# Stage 1-1 맵 반입 — 2026-09-08

S3 `Stage_1_1_OriginalCover_v001`에서 현재 활성화되어 있는 맵 외형만 추린 S2 반입본이다.
맵 아트 반입 후 **15×15 논리 그리드 배치**까지 진행한 상태다. 세부 칸 배치와 검증 상태는 `LogicalGrid.md`를 참고한다.

## 사용 위치

- 배틀 씬: `Assets/Scenes/Test/BattleTest01.unity`
- 맵 프리팹: `Assets/Prefab/Battle/Map/Stage_1_1_OriginalCover_v001.prefab`
- 개별 엄폐물: 같은 폴더의 `CargoCover`, `VentCover`, `ServiceBarrier` 프리팹
- 출처와 GUID, 이미지 해시, 분리 파트의 정렬 기준: `ImportManifest.json`

## 폴더

- `Sprites/Ground`: 기본 바닥과 엄폐물 아래 복원 바닥 6개
- `Sprites/Buildings`: 건물 파트 31개
- `Sprites/Props`: 소품 및 장식 파트 37개
- `Sprites/LowCover`: 기존 원화 엄폐물 3개
- `Materials`: 동일 설정의 복제본 99개를 통합한 머티리얼 74개
- `Shaders`: S2 렌더러에서 표시할 수 있도록 Pass 태그를 맞춘 Unlit 셰이더 1개

이미지 77개는 원본 PNG를 변경하지 않고 메타 파일과 함께 복사했다. 파일명에는 출처 버전 접두어를 붙여 동일한 Part/M 이름 충돌을 방지했다. 기존 S2 공용 아트 경로는 이동하지 않았다.

## 현재 배치와 표시

- S3의 논리 픽셀 좌표는 `x / 45`, `(1254 - y) / 45`로 월드 좌표에 대응한다.
- 원본 프리팹은 배율 1로 보존한다. BattleTest01의 씬 인스턴스는 `(0.5, 0.5, 1)`로 표시하여 전체 영역이 약 13.93 × 13.93 월드 유닛이다.
- BattleTest01 맵 오프셋은 사용자가 조정한 `(-0.45, 0.58, 0)`이다. 논리 시작 칸 `(1, 1)`은 유지한다. 이는 이전 크기 비교 때의 오프셋을 대체한다.
- 플레이어 VisualRoot도 편집 화면에서 월드 `(1, 1, 0)`으로 맞췄다. 캐릭터 배율 0.2, PPU 310, 시작 칸 값과 Animator는 유지했다. Main Camera는 `(1, 4.5, -6)`으로 옮겼고 줌 5.5는 유지했다.
- 맵 내부 분리 그림의 순서는 유지한다. 루트 SortingGroup `-200`으로 기존 캐릭터·전술 표시·Fog보다 아래에 그린다.
- `BackgroundParts`, `LowCover`, `RestoredGround` 아래 총 173개 SpriteRenderer를 보관한다.
- 기존 `MapVisualGrid`의 네 TilemapRenderer는 비활성 상태다. 벽·낮은 장애물 타일은 새 맵에 맞게 교체했고 논리 참조는 유지했다.
- 맵 밖 NPC와 건물에 걸리는 적 편대·순찰점은 통행 칸으로 조정했다. 사용자가 비활성화한 단말기·문은 유지했다.

## 다음 연결 작업

1. 15×15, cellSize 1로 배치한 논리 그리드를 실제 플레이에서 검증한다. 정적 검사에서는 통행 83칸 전체와 목표 경로가 연결된다.
2. 건물의 이동·시야 차단과 낮은 엄폐물 3칸을 배치했다. 실제 S2 판정은 Tilemap을 사용하며 엄폐물 BoxCollider2D는 접지 범위 참고다.
3. 캐릭터 앞뒤 Y 정렬과 건물 반투명을 S2 연출 계층에 연결한다. S3의 RouteReview/SeparatedMapWalk는 반입하지 않았으며, 현재 맵은 정적 표시다.
4. 해킹 성공 시 보안문 대신 StageGoal이 열리는 규칙을 연결한다. 현재 코드는 도착 즉시 클리어이며 해금 조건은 아직 없다.
5. 낮은 엄폐 자세 이미지는 별도 후속 작업이다. 이번 반입에는 포함하지 않았다.

## 캐릭터 기준 크기 비교 (2026-09-08)

- 맵 0.5배와 0.6배를 같은 카메라 줌에서 비교하고, 우선 0.5배를 적용했다. 이는 아트 비율 조정값이며 전 구간 통행이 확정된 값은 아니다.
- 유진 전투대기 PNG의 알파 32 초과 영역은 849×1187px이다. 현재 PPU 310과 배율 0.2에서 실제 보이는 폭 약 0.548, 높이 약 0.766유닛이다. 투명 캔버스 전체 크기로 인물 높이를 판단하지 않았다.
- S3 접지 Rect 중 y=478~535 사이 57px 간격은 0.5배에서 약 0.633유닛이다. 기존 이동 여백을 포함하면 더 좁아진다. 이는 특정 통로 표본이며 맵 전체의 최소 폭이나 실제 경로 연결 검증이 아니다.
- 크기 비교 당시에는 cellSize 1을 확정하지 않았다. 후속 논리 배치에서는 사용자 15×15/cellSize 1을 유지했고 칸 중심과 경로 연결을 정적으로 검사했다. 실제 캐릭터 가림·연출 검수는 별도다.
- 비교 캡처는 Library/Stage11ImportBackup/Scale_050.png, Scale_060.png와 Scale_050_Idle_Final-1.png에 있다. 마지막 캡처는 기존 전투대기 Sprite를 잠깐 표시한 검수본이며 캡처 후 원래 씬 Sprite를 복원했다.
