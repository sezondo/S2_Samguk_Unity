# 1-1 정비교 하부 — 구조 시안 v001

- 맵: 34×26, 좌하단 원점. 전 구간은 지상 1층이다.
- 시작: (14,4). 별도 도입 구간 없이 두 경로 선택으로 시작한다.
- 정면: 경비 6명, 다수 적 전투에 의한 실패 유도. 통로 자체는 목표까지 연결된다.
- 우회: 폐기물 사이 꺾인 골목 → 고립 경비 (25,16) → 단말 (27,19) → 뒷문 (25,21) → 목표 (25,23).
- 기둥: 중앙의 큰 벽 영역. 화면에 하부만 드러내고 전체 높이는 숨긴다. 기둥 북측의 좁은 통로는 지상 하부 시설이다.
- 낮은 엄폐는 기존 맵메이커 형식대로 표시하되 모든 추천 경로에서 피한다. 실제 Unity 점유는 이동 불가다.
- 위험 바닥·상부 정비교 우회로·추가 아이템 학습은 넣지 않는다.
- 닫힌 뒷문은 우회로의 마지막 한 칸을 차단한다. 문 앞 터미널에서 해킹 가능하다.
- 정면 실패와 우회 경비의 고립은 설계 의도다. HP/AP/시야/애드 전파, 해킹 거리와 튜토리얼 대사는 Unity에서 플레이 테스트해 확정해야 한다.
- 적 근접 위험 지표는 거리 기반 참고값이며 벽·시야·경계 전파를 시뮬레이션하지 않는다.

## 맵메이커 사용

S2_Map_Maker.html을 열고 '1-1 정비교 하부 시안 열기'를 누른다. 기본 '칸 살펴보기'에서 클릭하면 좌표, 지형, 배치물, 경로와 설계 메모가 표시된다. 편집 중 Shift+클릭 또는 우클릭도 조회만 한다. 방향키로 선택 칸을 이동할 수 있다. JSON v6은 칸 메모를 포함하며 기존 v4/v5 맵도 불러온다.
