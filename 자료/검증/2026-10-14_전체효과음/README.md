실제 튜토리얼 기록: 총격 2, 공격 투척 1, 검 베기 1, 맨손 1, 활 1, 망치 1, 쓰러짐 2, 정찰 이동 3, 회수 2, 발각 2, 해킹 시작/완료 각 1, 문/승강기 각 1, 수첩 펼치기/덮기 각 4. 전체 검사에서는 한 판에 등장하지 않는 몽둥이·석궁·기척·실패·페이지 넘김·실제 클릭도 따로 확인했다.

새 원본 50개의 길이·피크·RMS·클리핑은 stage11_sfx_audio_qa.json, 초기 볼륨과 정책은 stage11_sfx_catalog.json에 있다. 48kHz/16bit/mono/PCM, 원본 최대 피크 0.70, 클리핑 0. 실제 동시 조합의 음량/질감은 주인님 청취로 조정한다.

비교 청취 파일: 프로그램/S2/Assets/Art/Audio/Sfx/Stage11/Stage11_SfxPreview.wav. 다음 순서이며 각 소재 사이에 짧은 무음이 있다.

1. 검 정찰 투척 → 공격 투척 → 회수 → 검 베기 → 맨손
2. 망치 → 몽둥이 → 석궁 → 활 → 피격 → 회피 → 쓰러짐
3. 발각 → 기척 → 해킹 시작 → 완료 → 문 → 승강기 → 실패
4. 수첩 펼치기 → 덮기 → 넘김 → 메뉴 열기 → 닫기 → 클릭

재현 메뉴: Tools/S2/Verify 1-1 Full Audio Draft, Verify 1-1 Tutorial Draft, Verify Battle Manual and Menu, Verify Presentation Media. 각각 따로 실행한다. 자동 검사는 런타임 API·UI 이벤트에 의한 것이며 신규 플레이어의 물리 입력·학습·재미 검증을 의미하지 않는다.

소재는 Assets/Art/Audio/Sfx/Stage11, 조정 데이터는 Assets/Data/Battle/Presentation/Sound/Stage11에 있다. 총격은 기존 YujinGunFire/Hit/Miss 데이터에 남아 있다. 전체 음량은 씬 AudioManager의 Master Volume, UI 6종만 Play During Pause를 켠다. 초기 조립 메뉴는 기본 음량까지 다시 적용하므로 개별 음량 조정에는 사용하지 않는다.

이번 범위는 배틀 이벤트와 메뉴·수첩이다. 발소리·HUD 행동 선택음·Story 지속음·BGM·음량 저장 설정 UI는 추가하지 않았다. 승강기는 배틀 탈출 시점의 진입 작동음이며 후일담의 지속 상승음은 별도다.
