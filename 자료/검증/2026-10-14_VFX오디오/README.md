미디어 검사는 실제 Unity 플레이에서 VFX/오디오 풀 재사용, 이전 핸들 간섭 차단, 미등록 VfxData 재생, 동시 16개 한도, 시간 정지·재개, 전체 음량 변경, 담당 비활성화, 난수 분리, 총격 명중/회피별 발사음과 결과음 1회, 타격 VFX 동기화, 잔향과 큐 완료 분리, 실제 샘플 진행을 확인했다.

이관 보존 검사는 작업 전 보관한 소스·데이터·씬 사본과 비교했다. 13종의 프리팹·수명, 씬별 예열 개수·부모, 세 씬의 기존 모든 Transform/RectTransform 및 네 Combat 데이터의 매핑·수치·시간을 보존했다. 실행 C#의 VfxId/정적 매니저 조회도 제거됐다. 원래 미사용 데이터에 남은 구형 직렬화 값은 임의 삭제하지 않았다.

검사 중 해킹 프리팹의 데이터 누락을 발견해 원본과 인스턴스 참조를 보완했다. 편집기 재로드 뒤 세 씬 감사를 다시 수행했고, 보완한 최종 상태에서 전투 연출과 전체 튜토리얼을 재실행했다. 오디오 소스 프리팹을 기존 Assets/Prefab 폴더 체계로 정리한 뒤에도 세 씬 감사·미디어 검사를 다시 통과했다. 이동 시 에셋 GUID를 보존했다.

PlayerGun.png는 회피 VFX, HackComplete.png는 실제 해킹 완료 표시, cleared.png는 전체 튜토리얼 탈출 결과다. 전투 회귀 검사는 시작 대사와 독립적으로 연출 API를 실행하므로 캡처에 튜토리얼 말풍선이 남을 수 있다. 실제 튜토리얼 흐름은 별도 전체 검사에서 확인했다.

자동 검사는 런타임 API/UI 이벤트를 사용한다. 신규 플레이어의 물리 입력·규칙 이해도·사람의 청취 품질 승인을 의미하지 않는다. 청감은 주인님 피드백으로 조정한다. 기존 비교 시안 2번을 단발로 분리한 발사음과 별도 합성 명중/회피 음원은 임시 연결이다. 스토리/배경음/다른 행동의 효과음은 이번 범위가 아니다.

재현 메뉴: Tools/S2/Audit Presentation Media References, Verify Presentation Media, Verify Combat Stage, Verify 1-1 Tutorial Draft. 플레이 검사는 저장된 BattleTest01에서 각각 따로 실행한다.
