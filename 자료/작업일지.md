# 2026-05-16 작업 기록

## 핵심
- 말풍선 기반 대사 시스템 1차 구조를 전역 시스템으로 다시 잡았다.
- 기존 `DialogueRunner`, `DialogueTrigger` 중심 구조는 제거했다.
- `DialogueManager` 전역 싱글톤을 추가했다.
- 1차 정책은 한 번에 하나의 `DialoguePlaybackSession`만 허용한다.
- `DialoguePlaybackContext` 구조체를 추가해 `sessionId`, 시퀀스, 시작 트리거를 이벤트로 전달한다.
- `DialogueEventTrigger`는 바닥, 문, NPC, 이벤트존 같은 이벤트 오브젝트에 붙어 대사를 시작한다.
- 시작 방식은 `Interact(F)` 또는 `Touch`다.
- `DialogueSpeaker`는 자체 `speakerTag`, 말풍선 Anchor, 자기 `SpeechBubbleView`를 가진다.
- 대사 데이터는 CSV 전환을 고려해 `speakerTag`, `text`, `advanceByInput`, `advanceByTime`, `autoAdvanceTime` 구조로 정리했다.
- `DialogueSequenceData.canPlayerMoveDuringDialogue`로 시퀀스 단위 이동 가능 여부를 정한다.
- 발화자를 찾지 못하면 fallback 없이 오류를 띄우고 대사 세션을 중단한다.
- `PlayerMovementLock`을 추가했고, `PlayerMovement`는 FSM 조건과 이동 잠금 조건을 함께 확인한다.
