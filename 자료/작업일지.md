## 개요

`S2_Map_Maker.html`은 S2의 전투·도주 맵을 원하는 크기의 격자 위에서 빠르게 구상하기 위한 간이 맵 디자인 도구다.

Unity 프로젝트에 맵을 직접 생성하는 도구는 아니며, 실제 제작에 들어가기 전에 이동 경로와 적 배치, 엄폐물 위치를 시각적으로 검토하는 용도로 사용한다.

## 튜토리얼 맵의 핵심 목적

튜토리얼에서는 플레이어에게 다음 두 가지 선택지를 제시한다.

1. **정면 검문로**: 검문 병력과 직접 전투하며 통과하는 위험한 경로
2. **상단 해킹 지름길**: 단말기를 해킹하고 보안문을 지나 전투를 피하는 우회 경로

상단 해킹 지름길이 정면 검문로보다 안전하고 유리하게 설계되어야 한다. 이를 통해 S2가 적을 모두 처치하는 게임이 아니라, 상황을 판단하고 위험을 피해 탈출하는 게임이라는 점을 학습시킨다.

## 실행 방법

1. `서브 프로그램` 폴더의 `S2_Map_Maker.html`을 실행한다.
2. 파일이 기본 웹 브라우저에서 열리면 바로 사용할 수 있다.
3. 별도의 프로그램 설치나 인터넷 연결은 필요하지 않다.

## 주요 기능

- 가로·세로를 각각 4칸부터 128칸까지 지정
- 숫자 입력 즉시 기존 내용을 유지하며 오른쪽·아래쪽 맵 크기 변경
- 크기를 줄이면 아래쪽 행과 오른쪽 열부터 제거
- 클릭 및 드래그 배치
- 이동 가능 지역, 벽·건물, 낮은 엄폐물 표시
- 플레이어, 목표, 적, 해킹 단말, 보안문 외 다양한 색상의 기본 배치 아이콘 제공
- `+` 버튼을 이용한 사용자 배치 아이콘 추가
- `1번 경로`, `2번 경로` 등의 경로를 서로 다른 색으로 표시
- `+` 버튼을 이용한 추가 경로 생성
- 모든 경로의 길이와 적 근접 위험 칸 비교
- 배치 도구의 이름, 아이콘, 맵 표시 문자 및 색상 수정
- 실행 취소 및 다시 실행
- 원하는 파일 이름과 저장 경로를 지정해 JSON 저장 및 다시 불러오기
- 현재 맵을 PNG 이미지로 저장
- 브라우저에 최근 작업 자동 저장

## 표시 의미

| 표시 | 의미 |
|---|---|
| P | 플레이어 시작 위치 |
| G | 탈출 목표 위치 |
| E | 적 |
| H | 해킹 단말 |
| D | 보안문 |
| 빨간 점 | 기본 1번 경로 |
| 파란 점 | 기본 2번 경로 |

## 참고 사항

- 위험 칸은 경로 주변에 배치된 적과의 거리를 기준으로 계산하는 간이 지표다.
- 배치 아이콘의 이름과 표시 문자는 사용자가 수정할 수 있으므로 위 표는 초기 기본값이다.
- 시야 차단, 엄폐 효과, 실제 이동 비용 및 전투 AI까지 계산하는 게임 시뮬레이터는 아니다.
- 설계가 확정되면 저장한 이미지나 JSON을 참고해 Unity에서 실제 맵을 제작한다.
